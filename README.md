# Sayed Zaeem — Portfolio

A responsive, creative React portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `src/main.jsx` with your professional email address.
2. Replace the LinkedIn URL with your actual profile URL.
3. Verify the experience timeline and dates. The current timeline is based on available career context and is intentionally marked for confirmation.
4. Add app-store links, screenshots and individual case-study pages where available.
5. Confirm which projects can be publicly discussed and whether employer/client names may be shown.

## Deploy

The project can be deployed to Vercel, Netlify or any static hosting provider. Build output is in `dist/`.
